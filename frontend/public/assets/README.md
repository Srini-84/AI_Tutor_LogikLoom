# Assets Folder

Place your logo image here.

## Logo File

- **File name**: `logikloom-logo.png` (or `.jpg`, `.svg`, `.webp`)
- **Recommended size**: At least 120x120px for high DPI displays
- **Format**: PNG with transparency preferred, or SVG for scalability

The logo should be named `logikloom-logo.png` (or update the filename in `app/page.tsx` if using a different name/format).
